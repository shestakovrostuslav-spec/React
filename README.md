# ToDo Manager

Фінальний проєкт з React. ToDo Manager — односторінковий застосунок для ведення списку справ.

## Можливості

- Створення, редагування, видалення та позначення завдань виконаними.
- Категорії, необов’язковий дедлайн, пошук за назвою та фільтри за категорією і статусом.
- Збереження завдань у `localStorage` після перезавантаження сторінки.
- Імпорт прикладів через `fetch` з [DummyJSON](https://dummyjson.com/docs/todos). Для імпорту потрібен інтернет.

## Локальний запуск

Потрібен Node.js 24 з npm. Команди виконуються в корені репозиторію.

```bash
npm ci
npm run dev
```

Адреса за замовчуванням — `http://localhost:5173`.

## Структура проєкту

- `src/App.jsx` містить маршрути React Router і спільний стан завдань. Сторінки отримують стан через React Context.
- `src/pages/` містить сторінку списку (`/`) та сторінку форми (`/tasks/new`, `/tasks/:id/edit`).
- `src/components/` містить навігацію, рядок завдання та спільну форму створення і редагування з перевіркою назви.
- `src/tasks.js` містить категорії та запит до API.

## Перевірка

```bash
npm test
```

Тести Vitest перевіряють створення та редагування через форму, валідацію назви й дії з рядком завдання. Папка збірки `dist` і правило маршрутизації для Netlify задані в `netlify.toml`.

## 🚀 Інструкція із запуску на Vercal

### Клонування репозиторію
Клонуйте проєкт на свій комп'ютер:

```bash
git clone [https://github.com/shestakovrostuslav-spec/React.git](https://github.com/shestakovrostuslav-spec/React.git)
cd React
```

Встановлення залежностей
Встановіть усі необхідні пакети, зазначені в package.json:

```
npm install
```

Проєкт налаштований для автоматичного деплою на платформу Vercel під час злиття гілок у main.
