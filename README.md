# ToDo Manager

Навчальний SPA на React для списку справ. Завдання можна додавати, редагувати, видаляти й позначати виконаними. Є категорії, дедлайни, пошук за назвою та фільтри за категорією і статусом.

## Запуск

Потрібен Node.js 24 з npm. У терміналі з папки проєкту виконайте:

```bash
npm ci
npm run dev
```

Відкрийте адресу, яку покаже Vite, зазвичай `http://localhost:5173`.

## Як працює проєкт

- `/` показує список завдань, пошук, фільтри та кнопку імпорту.
- `/tasks/new` відкриває форму створення. `/tasks/:id/edit` відкриває ту саму форму з даними вибраного завдання.
- `TaskListPage` зберігає стан пошуку і фільтрів та передає завдання й обробники через props до `TaskItem`. Стан самих завдань піднято в `TasksProvider`, звідки його отримують обидві сторінки через React Context.
- Зміни зберігаються у `localStorage` цього браузера. Кнопка «Завантажити приклади з API» імпортує до п’яти англомовних завдань із [DummyJSON](https://dummyjson.com/docs/todos). Для імпорту потрібен інтернет.

## Перевірка

```bash
npm test
npm run lint
npm run build
```

Тести перевіряють форму створення й редагування та дії з елементом списку. `npm run build` збирає файли у `dist`.

## Розміщення на Netlify

У Netlify виберіть імпорт проєкту з GitHub і вкажіть гілку з готовим кодом. Файл `netlify.toml` задає команду `npm run build`, папку `dist` і правило для відкриття маршрутів React Router за прямим посиланням. Після успішної публікації Netlify покаже адресу сайту.
